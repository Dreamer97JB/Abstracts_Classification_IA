# Plan 02-01: Legacy-to-canonical theory mapping and supervision policy contracts

## Objective

Move Phase 2 supervised-source routing and theory mapping policy into versioned config files, then expose a package-based theory-mapping pipeline that can emit canonical supervised rows and unresolved review cases without editing the raw workbooks.

<must_haves>
- Theory mapping policy is config-driven rather than trapped in Python constants.
- Candidate supervised sources and train/eval/inference routing are represented in versioned config.
- Unresolved theory labels are exported explicitly for manual review instead of silently disappearing.
</must_haves>
