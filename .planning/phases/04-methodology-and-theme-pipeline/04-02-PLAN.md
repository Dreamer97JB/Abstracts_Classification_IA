# Plan 04-02: Implement governed theme outputs and separated analysis artifacts

## Objective

Replace notebook-only downstream topic work with a governed, lightweight theme-analysis path that writes separate outputs, prefers governed keywords, and remains traceable to the same Phase 4 run context.

<must_haves>
- Theme outputs are written as separate artifacts and do not overwrite theory or methodology columns.
- Governed keywords are preferred when available.
- Rows without keywords still receive deterministic fallback themes.
</must_haves>
